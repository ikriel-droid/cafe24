# Beta Validation Plan

## Goal

Validate that ClaimMate materially reduces CS handling time for Cafe24 merchants without lowering response quality.

## Target Beta Merchant Profile

- Korean Cafe24 merchant
- repeated cancellation / exchange / return inquiries
- at least one manager and one agent
- willing to provide weekly feedback

## Test Scenario

Run a short beta with real daily usage:
- connect Cafe24
- import live claims
- classify and draft replies through ClaimMate
- use follow-up queue and diagnostics
- compare handling time before and after

## Success Metrics

- faster first-response time
- reduced manual drafting time
- fewer missed follow-up items
- stable sync and webhook reliability
- acceptable AI review rate

## Review Cadence

- day 1 onboarding review
- week 1 operational review
- week 2 pricing and workflow review
- end-of-beta go / no-go decision
